# Color Palette

Source: https://builder.aws.com/community/student-builder-groups (AWS Builder Center, a Cloudscape-based dark theme)

## Core (dark theme)

| Role | Hex |
|---|---|
| Page / container background | `#080808` |
| Raised surface / hover dark | `#1a1a1a` |
| Border / divider (dark) | `#242424` |
| Subtle text / dark divider | `#3b3b3b` |
| Disabled text | `#6b6b6b` |
| Muted text / placeholder | `#909090` |
| Secondary interactive text | `#b7b7b7` |
| Secondary heading / body | `#e1e1e1` |
| Headings | `#f5f5f5` |
| Body text / links | `#f9f9f9` |

## Brand Accent (purple)

| Role | Hex |
|---|---|
| Accent, hover, active link (dark mode) | `#ca9aff` |
| Accent, vivid | `#b052ff` |
| Accent text (light mode) | `#7900be` |
| Deep purple | `#7300e5` |
| Light tint | `#f5edff` |
